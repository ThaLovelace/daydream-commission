# สมุดค่าคอม — Daydream Massage & Spa

## อัปเดตล่าสุด — สิ่งที่แก้ไข

1. **ราคาค่าคอมอ้างอิง** ในหน้า "ตั้งค่า" ตรวจสอบแล้วว่าตรงกับตารางค่าคอมของร้าน (หมวดของช่าง)
   และตอนนี้ **แก้ไขราคาได้เอง** จากในแอปเลย (แตะที่ตัวเลขในหน้าตั้งค่า) โดยรายการที่บันทึกไปแล้ว
   ในอดีตจะไม่เปลี่ยนค่าคอมย้อนหลัง
2. **ชื่อรายการเปลี่ยนเป็นภาษาไทยที่อ่านง่าย** (ยังใส่ชื่ออังกฤษเดิมไว้ในวงเล็บให้คุ้นตา) และ
   **จัดลำดับใหม่ให้แพ็ค 1-4 ขึ้นก่อน** แล้วตามด้วยรายการอื่น ๆ ทั้งในหน้าตั้งค่าและตอนเลือกบริการ
3. **หน้าบันทึกรายวัน**: ลบรายการได้อิสระโดยไม่กระทบรายการอื่น (ตัวเลขลำดับแค่เรียงใหม่ให้อัตโนมัติ
   ไม่ต้องลบทั้งหมดแล้วพิมพ์ใหม่) เพิ่มการกดลบแบบยืนยัน 2 จังหวะในตัวการ์ด (กันลบมือลั่น) และเพิ่มปุ่ม
   "เลิกทำ" กู้คืนรายการที่เพิ่งลบได้ทันทีถ้ากดผิด
4. **หน้ารายงานเดือน**: เอากล่องสรุปยอดที่ซ้ำกันออก เหลือกล่องสรุปยอดรวมกล่องเดียวด้านล่าง (รวม
   ค่าคอม + โบนัส 15% ถ้าถึงเกณฑ์) ให้เข้าใจง่ายขึ้น

### ต้องทำอะไรหลังดึงโค้ดนี้ไปใช้

โครงสร้างฐานข้อมูลเพิ่มคอลัมน์ใหม่ (`sortOrder` ใน Service) ต้องอัปเดตฐานข้อมูลก่อนใช้งาน:

```bash
npm install
npx prisma db push   # อัปเดตโครงสร้างตาราง (เพิ่มคอลัมน์ sortOrder)
npm run seed         # อัปเดตชื่อ/ราคา/ลำดับรายการให้เป็นชุดใหม่ (ไม่ลบรายการที่บันทึกไปแล้ว)
npm run dev
```


เว็บแอปสำหรับบันทึกค่าคอมมิชชันของช่าง มี login แบบง่าย (เลือกชื่อ ไม่ต้องใส่รหัสผ่าน),
บันทึกรายวัน, รายงานรายเดือนแบบการ์ดสรุป, เทียบยอดกับสลิปร้าน, และ export/print ได้

โค้ดนี้เป็นของคุณเอง มี **ฐานข้อมูลของตัวเอง** ไม่ได้พึ่งพา Claude อีกต่อไป
พุชขึ้น GitHub แล้ว deploy ได้ฟรีตามขั้นตอนด้านล่าง

## 1. รันบนเครื่องตัวเอง (local, ใช้ SQLite ไม่ต้องตั้งค่าอะไร)

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไปติดตั้งไว้ก่อน

```bash
npm install
npm run seed      # ใส่ข้อมูลตั้งต้น: สาขา, รายการบริการ, ผู้ใช้ชื่อ "อ้อ"
npm run dev
```

เปิด http://localhost:3000 — จะเจอหน้า login ให้เลือกชื่อ "อ้อ" ได้เลย

## 3. Deploy ฟรีจริง (Vercel + Neon Postgres)

SQLite ใช้ได้แค่ตอนรันบนเครื่องตัวเองเท่านั้น เพราะ Vercel ไม่มีดิสก์ถาวรให้เก็บไฟล์ฐานข้อมูล
ตอน deploy จริงต้องเปลี่ยนไปใช้ฐานข้อมูล Postgres (ฟรีได้ที่ Neon หรือ Supabase)

### 3.1 สร้างฐานข้อมูลฟรีที่ Neon
1. ไปที่ https://neon.tech สมัครฟรี (ใช้ GitHub login ก็ได้)
2. สร้างโปรเจกต์ใหม่ → คัดลอก "Connection string" (หน้าตาแบบ `postgresql://user:pass@host/dbname?sslmode=require`)

### 3.2 แก้โค้ดให้ใช้ Postgres
เปิดไฟล์ `prisma/schema.prisma` แก้บรรทัด:
```prisma
datasource db {
  provider = "sqlite"        // เปลี่ยนเป็น
  provider = "postgresql"    // แบบนี้
  url      = env("DATABASE_URL")
}
```

สร้างไฟล์ `.env` (ในเครื่องตัวเอง ไม่ต้อง commit ขึ้น git):
```
DATABASE_URL="<connection string จาก Neon>"
```

รันคำสั่งสร้างตารางบน Neon แล้วใส่ข้อมูลตั้งต้น:
```bash
npx prisma migrate dev --name init
npm run seed
```

commit และ push โค้ดที่แก้ (schema.prisma) ขึ้น GitHub อีกครั้ง

### 3.3 Deploy ที่ Vercel
1. ไปที่ https://vercel.com สมัครฟรี (login ด้วย GitHub)
2. กด "Add New Project" → เลือก repo ที่พุชไว้
3. ในหน้า "Environment Variables" ใส่:
   - `DATABASE_URL` = connection string เดียวกับที่ใช้ใน `.env`
4. กด Deploy

เสร็จแล้วจะได้ลิงก์เว็บ เช่น `https://daydream-commission.vercel.app`
เปิดจากมือถือ กด "เพิ่มไปยังหน้าจอโฮม" ก็ใช้เหมือนแอปได้เลย ฟรีตลอด (Vercel + Neon มี free tier
ที่เพียงพอสำหรับการใช้งานขนาดร้านเล็กสบายๆ)

## โครงสร้างข้อมูล (Prisma schema)

- **User** — ผู้ใช้ (ช่างแต่ละคน), มี `role` เผื่อขยายเป็นแอดมิน/เจ้าของร้านทีหลัง
- **Branch** — สาขา (Suriwong, The Kannas)
- **Service** — รายการบริการ ทั้งรายการหลัก (`category: "main"`) และรายการเสริม (`category: "addon"`)
  พร้อม `effectiveFrom` เผื่อร้านปรับเรทในอนาคต
- **Entry** — 1 แถว = ลูกค้า 1 ครั้ง คำนวณค่าคอมไว้ตอนบันทึกเลย (ไม่คำนวณสดทุกครั้ง)
- **EntryAddon** — รายการเสริมที่ติดมากับ Entry นั้น (เลือกได้หลายอันต่อ 1 ครั้ง)

## กติกาค่าคอมที่ระบบใช้อยู่

- ค่าคอม = ราคารายการหลัก + ผลรวมรายการเสริมที่เลือก + อื่นๆ (ถ้ามี) — คำนวณฝั่งเซิร์ฟเวอร์เสมอ
  (ไม่เชื่อตัวเลขจากฝั่งหน้าเว็บ กันข้อมูลเพี้ยน)
- เดือนไหนค่าคอมรวมถึง 8,000 บาท → ช่างได้โบนัสเพิ่ม 15% ของยอดเดือนนั้น
- โบนัส 300 บาท/วัน เป็นของแอดมินเท่านั้น **ไม่รวมอยู่ในระบบนี้** (ระบบนี้ทำเฉพาะฝั่งช่าง)

ถ้าร้านปรับราคาในอนาคต แก้ได้ที่ `prisma/seed.js` แล้วรัน `npm run seed` ใหม่
(รายการเก่าที่บันทึกไปแล้วจะไม่เปลี่ยนราคาย้อนหลัง เพราะค่าคอมถูกคำนวณไว้ตายตัวตอนบันทึกแล้ว)

## เกี่ยวกับระบบ login

ตอนนี้ login แบบง่าย (เลือกชื่อจากลิสต์ ไม่ต้องใส่รหัสผ่าน) เหมาะกับร้านเล็กที่ทุกคนใช้เครื่องของตัวเอง
ถ้าอยากเพิ่มความปลอดภัย (เช่น ใส่ PIN หรือรหัสผ่านจริง) บอกได้ ต่อยอดจากโครงสร้างนี้ได้ไม่ยาก
